DECISION TREE (Per Data Item):
════════════════════════════════════════════════════════════════════════════

    Data Item (cell object or blob)
         │
         ├─ Get prototypeIndex
         ├─ entry = registry.GetEntry(prototypeIndex)
         │
         └─ Check entry.IsInstancedAtLOD(chunkLOD):
            
            Is instanceAlways = true?
            ├─ YES → ALWAYS GPU instance (even LOD0)
            │
            Is chunkLOD = 0?
            ├─ YES → ALWAYS spawn GameObject (LOD0 exception)
            │
            Is shouldInstance = true?
            ├─ YES (LOD1+) → GPU INSTANCE
            │
            └─ NO (LOD1+) → SPAWN GAMEOBJECT


BLOB-SPECIFIC LOGIC:
════════════════════════════════════════════════════════════════════════════

    Blob data item
         │
         └─ Is it a single-instance blob?
            (radius ≈ 0, density ≈ 1)
            
            ├─ YES (single tree):
            │   └─ Is LOD0 AND NOT instanceAlways?
            │       ├─ YES → Convert to GameObject via BlobConverter
            │       │        Spawn via MapPrefabStreamer
            │       └─ NO → Add to GPU buffer
            │
            └─ NO (cluster):
                └─ Add to GPU buffer (too many to spawn)


COMPONENT CHAIN:
════════════════════════════════════════════════════════════════════════════

    ChunkObjectLoader
    ├─ Reads: CellObjectReader, CellBlotchReader
    ├─ Queries: MapObjectPrototypeRegistry
    ├─ Routes: BlobConverter (detection)
    ├─ Spawns: MapPrefabStreamer (LOD0)
    └─ Uploads: ImpostorRenderer (GPU)
               └─ Executes: CSExpandBlotches compute shader


CHUNK LIFECYCLE:
════════════════════════════════════════════════════════════════════════════

    ChunkManager: New chunk needed
         │
         └─ ChunkRegistry.OnChunkCreated(packed, face, lod)
            │
            └─ ChunkObjectLoader.HandleChunkCreated()
               │
               ├─ CellObjectReader.GetObjectsForChunk()
               │  └─ For each: route via registry
               │
               ├─ CellBlotchReader.GetBlobsForChunk()
               │  └─ For each: route via registry
               │
               └─ [First chunk?] SubmitGPUBuffer()
                  └─ ImpostorRenderer.Initialize(_gpuBlotches[])


    Player leaves chunk
         │
         └─ ChunkRegistry.OnChunkRemoved(packed, face, lod)
            │
            └─ ChunkObjectLoader.HandleChunkRemoved()
               │
               └─ MapPrefabStreamer.DespawnChunkObjects()
                  ├─ Return objects to pool
                  └─ Destroy chunk parent


REGISTRY CONFIGURATION MATRIX:
════════════════════════════════════════════════════════════════════════════

    shouldInstance  instanceAlways  LOD0              LOD1+
    ───────────────────────────────────────────────────────────
    FALSE           [ignored]       GameObject        GameObject
                                    (sourcePrefab)    (sourcePrefab)
    
    TRUE            FALSE           GameObject        GPU Instance
                                    (sourcePrefab)    (lodMeshes)
    
    TRUE            TRUE            GPU Instance      GPU Instance
                                    (lodMeshes)       (lodMeshes)


EXAMPLE TREE SETUP:
════════════════════════════════════════════════════════════════════════════

    Entry: "Oak Tree"
    ├─ shouldInstance: TRUE
    ├─ instanceAlways: FALSE
    ├─ sourcePrefab: OakTree_LOD0_Colliders
    ├─ lodMeshes: [LOD0_mesh, LOD1_mesh, LOD2_mesh, Billboard_mesh]
    └─ material: TreeInstanced
    
    Behavior:
    ├─ Cell object at LOD0 → Spawn sourcePrefab (collider, interactive)
    ├─ Cell object at LOD1+ → Spawn sourcePrefab (shared hierarchy)
    ├─ Blob (single) at LOD0 → Spawn sourcePrefab (collider, interactive)
    └─ Blob (single) at LOD1+ → GPU instance (use lodMeshes[1])


EXAMPLE GRASS SETUP:
════════════════════════════════════════════════════════════════════════════

    Entry: "Dense Grass"
    ├─ shouldInstance: TRUE
    ├─ instanceAlways: TRUE (no colliders needed)
    ├─ sourcePrefab: null (ignored)
    ├─ lodMeshes: [Tuft_mesh, Billboard_mesh]
    └─ material: GrassInstanced
    
    Behavior:
    ├─ Blob cluster → GPU instance at all LODs
    ├─ No GameObjects spawned
    └─ Compute shader expands blobs into individual instances
